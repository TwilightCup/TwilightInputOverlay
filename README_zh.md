# TwilightInputOverlay

一个用于《人类跌落梦境 / Human: Fall Flat》的 [BepInEx 5](https://docs.bepinex.dev/) 插件，可以在屏幕上显示输入操作 HUD。它以网格形式固定在画面左下角，显示移动键、跳跃、装死以及左右手操作，让你（或观众）随时看清正在按哪些按键。仅支持键鼠输入。

## 功能特性

- **按键网格 HUD**，显示 `W` / `A` / `S` / `D`、跳跃条（`—`）、装死（`Y`）以及左右手按键（`L` / `R`）：

  ```text
  [Y] [W] [L/R]
  [A] [S] [D]
  [  —  ]
  ```

- **跟随真实输入** —— HUD 会根据你在游戏内实际的键位和鼠标绑定亮起，重新绑定按键后依然正常（屏幕上的标签仍保持标准字母 `W`/`A`/`S`/`D`/`Y`/`L`/`R`）。
- **实时配置面板** —— 按 `Home` 键打开，所有修改立即生效。
- **颜色完全可定制** —— 可分别编辑 *闲置* 与 *按下* 两种状态下文本、边框和填充的颜色，支持 HEX 颜色编码或 RGBA 滑条。
- **布局调整** —— 可开关 HUD、开关按键文本、以左下角为锚点调整 X/Y 偏移、整体缩放，以及调整按键间距和圆角程度。
- **平滑按键过渡** —— 按键在闲置与按下样式之间淡入淡出，并可在设置中调整过渡速度。
- **多语言本地化** —— 内置英文和简体中文，放入语言文件即可扩展更多语言。

## 运行要求

- 已安装 [BepInEx 5](https://docs.bepinex.dev/) 的《Human: Fall Flat》。

## 安装方法

1. 下载最新版本：`TwilightInputOverlay-v{version}.dll`。
2. 将 DLL 复制到游戏的 `BepInEx/plugins/` 目录。
3. 启动游戏，左下角即会显示输入 HUD。
4. 按 `Home` 键打开设置面板。

## HSRTimer 集成

如果安装了 HSRTimer，TwilightInputOverlay 会自动集成到 HSRTimer 的设置面板中，作为一个 **输入显示** 标签页；此时不会创建按 `Home` 键打开的独立面板，请打开 HSRTimer 的设置面板进行配置。没有 HSRTimer 时，插件也能正常工作，并提供自己的独立面板。

## 使用指南

### 设置面板

面板包含以下几部分：

- **通用** —— 更改设置面板按键、切换语言。
- **HUD** —— 开关 HUD、开关按键文本、调整 X/Y 偏移、调整整体缩放。
- **动画** —— 调整闲置/按下淡入淡出的速度。
- **按键网格** —— 调整按键间距和圆角程度。
- **样式** —— 选择 *闲置* 或 *按下* 状态，然后用 HEX 编码或 RGBA 滑条编辑**文本**、**边框**和**填充**颜色。

所有修改都会实时生效，并在关闭面板或退出游戏时自动保存。

### 配置文件

首次运行时，插件会在 `BepInEx/config/TwilightInputOverlay/` 下自动生成配置文件：

- `settings.ini` —— 已保存的设置。可在游戏关闭时手动编辑，格式错误的行会被忽略。
- `lang/` —— 语言文件（`*.txt`）。放入新文件即可添加你自己的翻译。
